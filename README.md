# 7-Day Jump Start Diet App

A simple phone-friendly React/Vite web app for the 7-day reset diet tracker.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

1. Go to Vercel.com and create a free account.
2. Choose **Add New Project**.
3. Upload/import this folder or connect it through GitHub.
4. Framework should be detected as **Vite**.
5. Build command: `npm run build`
6. Output directory: `dist`
7. Deploy.

## Use on phone

Open the deployed link on your phone browser, then choose **Add to Home Screen**.

The app saves daily choices locally in the browser using localStorage.
